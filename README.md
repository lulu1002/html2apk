# PC Launcher

Launcher Android com visual de PC: área de trabalho com ícones, barra de tarefas,
menu Iniciar com busca, janelas arrastáveis (Este Computador, Bloco de Notas).

## Compilar
1. Suba este projeto para um repositório no GitHub (branch `main`).
2. O workflow `.github/workflows/build.yml` roda sozinho.
3. Baixe o APK em **Actions → último run → Artifacts → PCLauncher-debug**.

## Usar
Instale o APK, aperte o botão Home e escolha **PC Launcher** como início padrão.
- Toque longo na área de trabalho: troca o papel de parede
- Toque longo num app do menu Iniciar: fixar, info ou desinstalar
- Arraste as janelas pela barra de título
