# WG VPN

Cliente VPN Android (WireGuard) em Kotlin.

1. Suba esta pasta num repositório do GitHub (branch main).
2. Aba Actions > "Build APK" roda sozinho (ou "Run workflow").
3. Baixe o APK em Artifacts e instale.
4. No app: cole/importe sua config .conf e toque em Conectar.

Precisa de um servidor WireGuard (VPS) ou config de um provedor.
