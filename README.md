# TV Aberta

App Android (Kotlin + Media3/ExoPlayer) para assistir canais de TV abertos pela internet.
Carrega listas M3U públicas (padrão: iptv-org, Brasil), com busca, categorias, favoritos,
tela cheia e troca rápida de canal.

## Compilar pelo GitHub Actions
1. Envie estes arquivos para um repositório (branch `main`).
2. Aba **Actions** → **Build APK** → baixe o artefato **tv-apk** (debug e release).

## Observações
- O app não hospeda canais: ele só reproduz os links das listas públicas.
- Alguns canais saem do ar ou têm bloqueio geográfico; isso é normal nessas listas.
